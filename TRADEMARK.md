# NeuraBSD Trademark Policy

This document governs the use of the NeuraBSD name, official logos, slogans, and related branding assets. Protecting our brand identity is crucial to ensure users can verify the integrity, security, and authenticity of their operating system installation.

---

## 1. Protected Intellectual Property

The following assets are protected trademarks of the NeuraBSD project and its creator, Daniel Hilbert (CodeAkrobat):
* **The Brand Name:** NeuraBSD™
* **Core Component Identity:** CoreSeed™, DaemonPath™, AxonSurface™, NeuraCore™.
* **Official Visual Identity:** All official logos, custom desktop icons, boot splash-screens, and typography located in `share/branding/`.

---

## 2. Permitted (Non-Commercial) Use

You do **not** require explicit written permission for the following activities, provided you do not imply official endorsement by the NeuraBSD project:
* **Community & Education:** Using the name in educational articles, review videos, forum discussions, academic papers, or community-driven documentation.
* **Graphics & Fan-Art:** Creating fan-art, desktop wallpapers, or customized system themes, as long as they are distributed free of charge.
* **Development Forking:** Under the BSD 3-Clause License, you are completely free to fork the source code. However, if you distribute a modified version of the operating system (e.g., custom ISO images), **you must remove all official NeuraBSD trademarks, branding assets, and logos**, and rename your distribution entirely.

---

## 3. Restricted Use (Explicit Authorization Required)

You **MUST** obtain explicit, prior written permission from the Project Lead (`lead@neurabsd.org`) for any of the following uses:
* **Commercial Redistribution:** Selling physical installation media (USB/CDs), pre-installed hardware devices, or cloud instances utilizing the NeuraBSD name or logos.
* **Merchandise & Advertising:** Producing and selling apparel, stickers, or hardware accessories branded with NeuraBSD assets, or using the assets in paid advertising campaigns.
* **Corporate Hosting:** Offering commercial enterprise support, customized commercial distributions, or using the NeuraBSD identity for corporate service models.

## 4. Visual Compliance & Industrial Design Identity

To achieve a cohesive, heavy-duty industrial aesthetic inspired by legacy Solaris workstations and robust Siemens engineering, the NeuraBSD ecosystem enforces a strict visual matrix. The interface balances classic, predictable Unix usability with a razor-sharp, modern surface execution.

### 🎨 Core Color Specifications
The NeuraBSD interface deployment utilizes an ultra-high-contrast, machinery-inspired palette. Component designs, terminal emulators, and the AxonSurface DE must strictly target these hexadecimal specifications:

| Component Accent | Context Purpose | Hexadecimal Vector |
| :--- | :--- | :--- |
| **Industrial Cyan** | Primary UI Controls, Active States, High-Visibility Highlights (Siemens-inspired) | `#00A3A3` |
| **Traditional BSD Red**| Protected branding vectors, specific critical alerts, native "BSD" logo lettering | `#D32F2F` |
| **Deep Matrix Blue** | Primary Window/Desktop backgrounds, high-contrast structural layers (Dark-Gray-Blue) | `#0B111A` |
| **Chassis Gray** | Secondary text, borders, inactive controls, industrial hardware shading | `#5A6573` |
| **Industrial Silver** | Primary high-readability typography, raw telemetry metrics, clean workspace vectors | `#D1D5DB` |

### 🚫 Prohibited Structural Modifications
* **Logo Vector Shifts:** The official logo may be updated to feature Industrial Cyan instead of the legacy blue; however, the explicit red coloration within the "BSD" letters must remain unmodified.
* **No Distortion:** Scaling, stretching, or skewing official graphic files is strictly prohibited.
* **Contextual Isolation:** Logos must maintain a safety margin of empty space around them and cannot be mixed into third-party corporate logos.
